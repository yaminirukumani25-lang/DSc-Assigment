# DSC212 – Recursive Spectral Modularity Optimization on Karate Club Network

## Project Description

This project explores the structure of a social network by identifying communities and analyzing how it is divided into smaller groups using recursive spectral partitioning.

It also tracks and visualizes structural network dynamics, node metrics evolution across iterations, and community segmentation.

## Dataset

**Zachary's Karate Club Network**

A well-known social network dataset representing friendships between members of a university karate club.

## Objectives

- Understand the structure of a real-world social network.
- Apply spectral methods for community detection.
- Implement recursive modularity optimization.
- Analyze network properties and community structures.
- Visualize the evolution of communities across iterations.

## Project Outcomes

The project demonstrates how spectral graph theory and modularity optimization can be used to identify meaningful communities within a network.
